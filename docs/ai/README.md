# AI environment

Document the local and cloud AI tools used in the development workflow.

For each tool or model, record:

- Purpose and typical tasks
- Installation / update method
- Hardware requirements and practical limitations
- Where configuration lives (never publish secret values)
- Safe start, stop, backup, and troubleshooting steps

Local AI tooling previously used includes Ollama and OpenClaw. Re-check the current installation and model list before documenting exact versions or configuration.

**Security:** never commit API keys, bot tokens, credentials, private endpoints, chat exports, or unredacted configuration files. Use sanitized examples such as `.env.example`.
