# Scripts

Store reusable setup and maintenance automation here.

Before adding a script:

1. State what it changes.
2. Make it safe to run more than once where practical.
3. Avoid destructive defaults.
4. Validate prerequisites and report errors clearly.
5. Include a dry-run or confirmation for consequential changes.
6. Document how to verify the result.

Scripts should not contain credentials or machine-specific secrets.
